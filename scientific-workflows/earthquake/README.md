# Earthquake — California Seismic Analysis

Analyze **12,160 real USGS observations** from California, magnitude ≥3, between 2000-01-01 and 2025-12-31. The original Pegasus scientific programs perform pattern analysis, mapping, anomaly detection, DBSCAN clustering, statistical aftershock estimation, hazard assessment and seismic gap analysis.

## Measured execution

The native AkôFlow daemon execution completed **11/11 activities in 407.717 seconds** on the homeserver using two local Docker lanes. Its manual plan contains placeholder predicted timings; those predictions are not measured benchmark results. All activity computations ran offline against the frozen observation catalog.

## Reproduce this workflow

[Download the complete source bundle, frozen USGS catalog, Dockerfile, pinned dependencies and configuration](https://hub.akoflow.com/showcase-results/scientific/earthquake/source.tar.gz). Extract it, enter `akoflow-examples/scientific-workflows/earthquake`, and run `./prepare.sh` followed by `./run.sh` with Docker and Go installed. The archive includes the shared Go runner and module files. Preparation can need network access; execution uses the frozen input. Allow 4 CPU cores, 8 GiB RAM and 5 GiB disk as an initial capacity recommendation rather than a measured minimum.

To import into Desktop, use the version-specific URI shown by the Hub. Configure local Docker with the companion environment, execution scope and topology from the source archive, plan the workflow and execute. No GCP resources are provisioned by this profile.

Immutable image: `hub.akoflow.com/akoflow-examples/earthquake@sha256:f0fa40c0f1fce87927a1b82e36968990bd2884ba21b12d2b9f717fdbb941f171`. This registry alias distributes the exact image used by the measured execution, with identical image ID. The historical capture retains the original local tag and source execution identifiers; changing its distribution address does not represent a second scientific execution.
