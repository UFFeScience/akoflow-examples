# Montage 050 — Deployment Profile Compatibility Bundle

This compatibility bundle belongs to the [single Montage workflow publication](https://hub.akoflow.com/o/akoflow/scientific-workflows-montage-050). Use its separate local and GCP execution profiles; this bundle does not represent a second experiment.

This profile preserves the complete original Montage 050d computation: 58 activities, 138 file handoffs, twelve FITS observations, three 1800×1800 mosaics and four PNG previews. All activities execute through local Docker.

The measured reference execution is shared with the Montage 050 local showcase because the executable DAG, input data, image filesystem and runtime configuration are identical. This is explicitly a shared reference capture, not a second independent experiment and not evidence of a GCP execution. The public capture preserves its original execution identifiers.

The [original cloud/local configuration](https://github.com/UFFeScience/akoflow-examples/blob/bf4539082b4c8bcf97197046c251c6174d314e24/real/montage-cloud-local/workflow.json) is retained as a separate historical version for users who configure GCP resources. Its four on-demand worker placements and predicted values are not measured by the local reference run.

## Inputs, outputs and execution

The pinned image includes the twelve original FITS observations and Montage executables. Use the source image's upstream dataset terms before redistributing the input observations. Configure local Docker using the companion environment, scope and topology definitions, import the public local-profile URI, create a plan and execute. On Apple Silicon the image requires amd64 emulation.

`./prepare.sh && ./run.sh && ./validate.sh` executes and validates the same local profile with Go and Docker. This is a full scientific workload, not a short timing simulation. The generated FITS and PNG files are validated before publication.
